# App 组件库素材来源

以下文件原样复用自 Aildo-Android/ui/src/main/res/drawable-nodpi/，仅重命名以供官网使用：

| 官网文件 | App 源文件 | 用途 |
|---|---|---|
| help.webp | recharge_help_icon.webp | 活动规则与常见问题问号图标 |
| star.png | mall_sub_equity_star.png | 规则条目、标题和奖励预告的四角星 |
| star-chain.webp | remote_bg_decor_left.webp | 面板边缘星链装饰 |

奖励预告仅表示已确认的类别，不代表实际奖励素材或解锁资格；正式奖励图片仍来自活动接口。
